Potential bug: darkness earlier set as random.randint(8,25) * params["stain_intensity"], then later multiplied again by params["stain_intensity"]: this double-multiplies stain intensity (so stains may be too strong). You probably intended only one multiplication — remove one factor.

Edge cases: random.randint(0, width-100) assumes width > 100. If not, randint(a,b) where b

Performance note: inner loops create stain_mask with nested loops — O(size²) per stain. For big images and many stains this will be slow.
